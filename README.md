# Leverage Computer skills

**[→ Sign up for Leverage Computer](https://app.leverage.computer/login?mode=signup&utm_source=github&utm_medium=readme&utm_campaign=leverage-computer-skills)**: free, no card.

[![skills.sh](https://skills.sh/b/leverage-computer/skills)](https://skills.sh/leverage-computer/skills)

Run Claude Code and Codex on persistent cloud machines your team can watch, steer and approve. [Leverage Computer](https://leverage.computer) is the team agent workspace: agents keep working when laptops close, share memory and skills, and every tool call goes through one gateway with approvals.

```sh
npx skills add leverage-computer/skills
```

Then ask your agent something like *"run this overnight"*, *"share this session with my teammate"* or *"ask me before the agent deploys"*. It sets you up on Leverage and runs the task.


## Start here

- **[`leverage-cloud-agents`](skills/leverage-cloud-agents/SKILL.md)**: Sign up and run your first task on a Leverage cloud machine.

## Cloud and always-on

- **[`background-agents`](skills/background-agents/SKILL.md)**: Hand a task to an agent on its own cloud machine and keep working.
- **[`overnight-agents`](skills/overnight-agents/SKILL.md)**: Runs that survive the night, with the lid closed and no blocking prompts.
- **[`parallel-cloud-agents`](skills/parallel-cloud-agents/SKILL.md)**: Many agents at once, each on its own machine and checkout, tracked in one inbox.
- **[`remote-devbox`](skills/remote-devbox/SKILL.md)**: An always-on machine for your agents without a Mac mini, tmux or a VPS.
- **[`agent-handoff`](skills/agent-handoff/SKILL.md)**: Move a live session, with its history, off your laptop or to a teammate.
- **[`scheduled-agents`](skills/scheduled-agents/SKILL.md)**: Recurring agent work that runs while every laptop is closed.

## Governance

- **[`safe-yolo-mode`](skills/safe-yolo-mode/SKILL.md)**: No permission prompts on an isolated machine; approvals only for real-world actions.
- **[`agent-approvals`](skills/agent-approvals/SKILL.md)**: Risky tool calls wait for someone on the team to approve, edit or deny.
- **[`agent-governance`](skills/agent-governance/SKILL.md)**: One set of allow, ask and deny rules for every agent in the company.
- **[`agent-audit-log`](skills/agent-audit-log/SKILL.md)**: Every tool call, the rule that allowed it and who approved it.
- **[`agent-secrets`](skills/agent-secrets/SKILL.md)**: Keys never enter the agent's machine.

## Team

- **[`share-agent-session`](skills/share-agent-session/SKILL.md)**: A link teammates use to watch, steer or take over a live session.
- **[`team-agent-memory`](skills/team-agent-memory/SKILL.md)**: What one session learns, every teammate's agent knows.
- **[`shared-agents-md`](skills/shared-agents-md/SKILL.md)**: One AGENTS.md every agent reads, across repos and harnesses.
- **[`team-agent-skills`](skills/team-agent-skills/SKILL.md)**: Roll skills out to the whole team with one update.
- **[`agent-inbox`](skills/agent-inbox/SKILL.md)**: One inbox for everything your team's agents are waiting on.
